# Natural entrance and exit paths

Replaced the flat yellow approach bands and bordered entrance/exit tiles with cached textured ground decals. The new paths use muted soil colors matched to each biome, multiscale grain, uneven worn edges, sparse grass blades and a gradual fade into the build field. No raised outline, flat yellow stripe, round platform or decorative stones are added.

The paths retain the existing gate coordinates and direction and extend to the viewport edge. Vertical approaches rotate the same texture correctly. Entrance/exit markers,16×12grid, blocked gate cells and simulation routing are unchanged.

Windows rendering inspected at1920×1080on forest, sand and ice maps, including vertical approaches. Actual captures are in `artifacts/natural-paths`. Windows and Android Release builds checked. These textures are generated by the existing code-native raster pipeline, cached and disposed through Painter; there is no extra external artwork dependency.
