# Store submission checklist

The presence of these files does not mean a store submission, age rating or device certification has occurred.

## Google Play

- [ ] Publisher account and final application ID confirmed.
- [ ] Release ARM64 AAB signed with publisher-controlled upload key; key backed up outside the repository.
- [ ] Target API and native library/page-size requirements checked against the rules in force on submission day.
- [ ] Release tested on low-, medium- and high-performance physical Android devices.
- [ ] Landscape layout, screen cutouts, 48 dp targets, background/lock/resume and audio route changes tested.
- [ ] Final icon and real gameplay screenshots exported at required sizes.
- [ ] Paid-app price, countries, content-rating questionnaire, data-safety declaration, privacy URL and support email completed.

## Steam

- [ ] Publisher account, Steam App ID and Steamworks permissions supplied.
- [ ] Release Windows x64 depot runs without administrator rights on a clean system.
- [ ] Steam achievements, language initialization and profile/progress cloud synchronization tested.
- [ ] Offline gameplay tested with Steam unavailable.
- [ ] Required capsules and real screenshots exported at current Steamworks dimensions.
- [ ] System requirements based on measurements, price, content survey and support information completed.

## Shared acceptance

- [ ] All eight maps and all three difficulties have documented winning playthroughs.
- [ ] Classic/Extended 100-wave campaigns and long Endless sessions tested.
- [ ] Save/restore, backup recovery and format migration pass.
- [ ] 300 enemies / 200 towers / 600 projectiles or effects at 2× measured on target devices.
- [ ] Licenses packaged; unresolved release-blocking defects are zero.
- [ ] Owner approves final publication.
